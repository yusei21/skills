# ECC for Gemini → Antigravity CLI (`agy`)

> **⚠️ The Gemini CLI was discontinued for individual accounts on 2026-06-18**
> and replaced by **Antigravity CLI** (`agy`). This legacy `GEMINI.md` is kept
> only for backward compatibility, since `agy` still reads from `~/.gemini/`.
>
> The active instruction layer now lives at:
>
> - **`.gemini/antigravity-cli/AGENTS.md`** — workflow, standards, security
> - **`.gemini/config/mcp_config.json`** — centralized MCP config (replaces the
>   old `~/.gemini/settings.json`)
>
> To migrate any legacy Gemini CLI plugins, run: `agy plugin import gemini`

See [`antigravity-cli/AGENTS.md`](./antigravity-cli/AGENTS.md) for the full,
current guidance.
